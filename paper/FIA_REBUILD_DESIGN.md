## 2. 样地纳入规则

依次应用，每一步剔除的样地数都记入执行记录。

1. **州**：上述十州。
2. **年度清查**：`PLOT.KINDCD` ∈ {1, 2, 3}（初次、复测、替换样地），且 `MEASYEAR` ≥ 2000。周期清查（`KINDCD` = 0）全部剔除；现表 Florida 那 5,355 个 1980–1995 年的样地会在这一步自然去掉。
3. **标准样地**：`QA_STATUS` = 1（标准生产样地）、`INTENSITY` = 1（基础网格，不含加密样地，以保持等概率样本），`PLOT_STATUS_CD` = 1（至少一个可达的有林条件）。
4. **最近一次测量**：样地按 (`STATECD`, `UNITCD`, `COUNTYCD`, `PLOT`) 识别，每个取 `MEASYEAR` 最大的一次；仍相同则取 `INVYR` 最大，再相同取 `CN` 最大。
5. **全为有林可达**：该次测量中，凡 `CONDPROP_UNADJ` > 0 的条件，`COND_STATUS_CD` 都是 1。部分有林、部分非林或不可达的样地剔除。这样结局可以直接按整块样地算，不需要选择每英亩林地的分母。这种做法偏向林内样地，要在 Methods 写明。
6. **结局可算**：样地上的活立木（`STATUSCD` = 1）`DRYBIO_AG` 与 `TPA_UNADJ` 都不缺。若有树缺值，整块样地剔除，不插补。没有活立木的样地保留，结局记为 0。

## 3. 结局与协变量

**结局 Y（主结局）。** 活立木地上生物量密度，单位 Mg ha⁻¹：

  Y = 0.0011209 × Σ_{活立木} `DRYBIO_AG` × `TPA_UNADJ`

- `DRYBIO_AG` 以磅计，`TPA_UNADJ` 已含微样方、子样方和大样方各自的扩展；1 lb ac⁻¹ = 0.0011209 Mg ha⁻¹。
- 不乘 POP 表的无响应调整因子：第 2 节第 5 条已要求整块样地都是有林可达。
- 只算地上部分，与 GEDI、ESA CCI 同口径。现表元数据写的是"地上加地下"，Methods 要写明这里只算地上。
- 碳另记一列：C = 0.0011209 × Σ `CARBON_AG` × `TPA_UNADJ`（Mg C ha⁻¹）。CO₂e = C × 44/12。正文的吨数一律由这一列换算，不用"生物量 × 0.47"之类的近似。

**协变量。** 按现表 X1–X12 的列结构重建，含义不变，`experiments/data.py` 与 `run_carbon.DROP` 的列号因此不必改。条件级变量取 `CONDPROP_UNADJ` 最大的条件；仍相同则取 `CONDID` 最小的条件。

| 列 | 含义 | FIADB 字段与算法 | 与现表的关系 |
|---|---|---|---|
| X1 | 海拔级 | `PLOT.ELEV`（英尺）× 0.3048，分为 0–500、500–1000、1000–1500、1500–2000、>2000 m 五级 | 级别标签相同 |
| X2 | 坡度级 | `COND.SLOPE`（%）：Flat < 5，Gentle 5–20，Moderate 20–40，Steep ≥ 40 | 现表阈值没有记录，此处自定，不求逐值一致 |
| X3 | 坡向 | `COND.ASPECT`（度；0 表示平地、无坡向） | 相同 |
| X4 | 热负荷 | McCune & Keon (2002) 式 3，用纬度、坡度（由 % 换成度）和折叠坡向 \|180 − \|坡向 − 225\|\|。提取脚本冻结前，对照原文核对系数 | 现表的 X4 与纬度有关，像是同一类指数，但公式没有记录，不求逐值一致 |
| X5 | 断面积 | Σ_{活立木, `DIA` 不缺} 0.005454 × `DIA`² × `TPA_UNADJ`（ft² ac⁻¹）× 0.229568 → m² ha⁻¹ | 都带扩展因子 |
| X6 | 每公顷株数 | Σ `TPA_UNADJ` × 2.47105 | 改为带扩展因子（现表不带） |
| X7 | 平均胸径 | 以 `TPA_UNADJ` 加权的 `DIA` 平均（英寸） | 现表算法未记录 |
| X8 | 平均树高 | 以 `TPA_UNADJ` 加权的 `HT` 平均（英尺） | 现表算法未记录；仍是 site + 树高地图中代替激光雷达冠层高度的变量 |
| X9 | 林型 | `COND.FORTYPCD` | 相同 |
| X10 | 林分大小级 | `COND.STDSZCD` | 相同 |
| X11 | 立地级 | `COND.SITECLCD` | 相同 |
| X12 | 地貌级 | `COND.PHYSCLCD` | 相同 |

- 没有活立木的样地，X5–X8 记为 0。
- 其他列：`lat`、`lon` 取 `PLOT.LAT`、`PLOT.LON`（公开坐标）；`region` 是州的两字母缩写；`fips` 由 `STATECD` 与 `COUNTYCD` 组成；`time` 取 `MEASYEAR`。
- 三种地图的特征分层（site、site + 树高、全部地面清查）沿用 `run_carbon.DROP`，不改。
